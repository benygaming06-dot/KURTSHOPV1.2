# KURTSHOP INVENTORY V1.2

Android inventory app for KURT DHYLAN MOTO SHOP.

## V1.2 updates
- Shopping Cart screen with selectable items
- Automatic total for selected items
- Quantity +/- controls
- Checkout customer name and date
- Receipt-style checkout summary with items, prices and total
- Selected items are removed from cart after checkout
- Product stock is automatically reduced after checkout
- Existing offline local storage retained
- Responsive UI retained
- Android 15 / SDK 35
